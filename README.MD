# Boa Compra - Relatório de Vendas

Bem-vindo ao Boa Compra! 🛒💻 Este é um projeto simples que foi criado como parte de um treino e estudo para aplicar conceitos de Node.js, API RESTful, JavaScript e Máscaras de Entrada para um sistema de relatórios de vendas de produtos de informática.

## 🚀 Sobre o Projeto

O Boa Compra é um sistema simples que permite cadastrar, editar, excluir e listar produtos de informática vendidos em uma loja. A loja pode ser física ou online. O projeto inclui funcionalidades para filtrar vendas por descrição, marca, modelo e data.

## 🛠️ Tecnologias Utilizadas

- **Node.js**: Ambiente de execução JavaScript no servidor.
- **Express.js**: Framework para criar a API RESTful.
- **JavaScript**: Para a lógica de front-end e back-end.
- **HTML5**: Estrutura básica da página web.
- **CSS**: Para o design básico da interface.
